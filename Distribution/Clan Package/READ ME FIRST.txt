OSRS DASHBOARD  -  Clan Edition
===============================

WHAT THIS IS
  A one-click dashboard for your Old School RuneScape account. It reads the
  screenshots RuneLite already saves and turns them into your own private
  account chronicle: current stats, your maxing journey, luck, bosses, loot,
  favorite memories, and a screenshot-backed historical timeline.


WHAT YOU NEED
  - RuneLite, with the Screenshot plugin on (it's what already saves your
    level-up and drop pics - most people have it enabled).
  - A Windows PC.


HOW TO RUN IT
  1. Double-click  "OSRS Dashboard.exe".  (If you downloaded it from
     GitHub it will be named "OSRS.Dashboard.exe" - same file.)

  2. If Windows shows a blue "Windows protected your PC" box, click
     "More info", then "Run anyway". That box just means the app isn't from
     the Microsoft Store - nothing is being installed and nothing is unsafe.

  3. A black window opens and lists the characters it found. Type the number
     next to the one you want to track and press Enter.

  4. It builds your dashboard and opens it in your web browser. The black
     window stays available while you use the dashboard, then closes itself
     a few seconds after the last dashboard tab closes.

  5. Use "Refresh dashboard" in the page whenever you want to scan again.
     Use the navigation on the left to explore the seven pages, and heart any
     screenshot to save it as a Favorite Memory.


WILL IT MESS WITH MY FILES?
  It never edits, moves, or deletes your screenshots. It creates the dashboard
  page and small JSON files for XP history, known bosses, favorites, and local
  dashboard caches next to your screenshots. Everything runs on your own PC
  and nothing is uploaded.


SEE THE CODE YOURSELF
  Not comfortable running a file you can't see into? Fair. The full source is
  published here, and it's the exact code this build was made from:
    https://github.com/Ralten-OSRS/osrs-dashboard


REFRESHING IT LATER
  Keep playing and taking screenshots like normal. Use the Refresh button in
  the dashboard while its tab is open. If you closed the dashboard, run the
  exe again. The more days you refresh, the better the "XP per day" tracking
  inside Maxing Journey gets.


WHERE YOUR DASHBOARD LIVES
  It saves next to your screenshots as "osrs_dashboard.html". Start it through
  the exe so Refresh and Favorites are available.
