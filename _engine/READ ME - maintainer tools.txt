These are maintainer tools, not things you need to run.

Update Drop Tables.bat
  Re-reads every boss drop table, rate, category and Combat Achievement
  list from the OSRS Wiki into _engine/boss_drops_generated.py, which is
  what a build bundles. You rarely need this by hand: Distribution/
  1 - BUILD THE EXE.bat runs it automatically before every build, and the
  dashboard looks up bosses it has never seen on its own as you play.
  Reach for it only to refresh bundled tables without doing a full build.

Audit Shared Drops.bat
  Lists items that appear on several bosses' drop tables. Items on four or
  more are classified as shared automatically, so this is a diagnostic for
  the rare judgement call, not a release step.
